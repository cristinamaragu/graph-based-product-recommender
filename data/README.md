# Data

The full analysis uses **Online Retail** (Daqing Chen, 2015), UCI Machine Learning
Repository, licensed CC BY 4.0, DOI: https://doi.org/10.24432/C5BW33.

Download `Online Retail.xlsx` from https://archive.ics.uci.edu/dataset/352/online+retail
and place it in **`data/Online_Retail.xlsx`**. It is intentionally not bundled.

`sample_transactions.csv` contains **invented example transactions** for an offline
API demo and tests, not the real retail dataset or a research result.
